## 一句话

**给它一个需求(不是接口文档),它从"读懂代码"到"生成用例 → 真实执行 → 算充分性 → 缺陷归因 → 出报告"全自动跑完,还能指挥多个 AI 当员工协作。全程本地、不出网。**

一条命令看全貌:

```bash
python pipeline.py --issue ISSUE-001
# → 执行 → 性能 → 充分性 → 归因 → 报告,5 段全自动
```

## 它和普通"AI 测试"最大的不同

普通 AI 测试:**你给接口 → AI 生成用例 → 完事**(全不全?没人知道)

这个平台:
1. **起点是需求,不是接口** —— 它自己读源码找该测什么(平台,不是工具)
2. **充分性可度量** —— 用源码当分母反推覆盖率,告诉你"只测了 48%,漏了这几项"
3. **结果不伪造** —— blocked 不当 failed,48% 不粉饰成 100%

**核心信条:AI 能力由模型决定,可靠性由你构建的验证系统决定。**

## 诚实边界(先说清)

- UI 测试:执行器有骨架,但演示系统是纯后端无 UI,没接;浏览器自动化真经验在我的 RPA 项目。

- 覆盖率目前是关键词匹配级,精确解析是下一步。
